## 解題說明

本題要求實現一個遞迴函式，計算阿克曼函數（Ackermann function）。

### 解題策略

1. 使用遞迴函式將問題拆解為更小的子問題，依據數學定義進行分支：
   $$A(m,n) = \begin{cases} n+1 & \text{if } m=0 \\ A(m-1, 1) & \text{if } m>0 \text{ and } n=0 \\ A(m-1, A(m, n-1)) & \text{if } m>0 \text{ and } n>0 \end{cases}$$
2. 當 $m=0$ 時，返回 $n+1$ 作為遞迴的結束條件。  
3. 主程式讀取使用者輸入的 $m$ 與 $n$，呼叫遞迴函式，並輸出計算結果。

## 程式實作

以下為主要程式碼：

```c
#include <stdio.h>

int a(int m, int n){
    if(m==0) return n+1;
    else if (n==0) return a(m-1,1);
    else return a(m-1,a(m,n-1));
}
int main(){
    int b,c;
    scanf("%d%d",&b,&c);
    printf("%d",a(b,c));
}
```

## 效能分析

1. 時間複雜度：時間複雜度極高，大約為 $O(A(m, n))$，增長速度遠超指數級別。
2. 空間複雜度：空間複雜度受限於遞迴的堆疊深度，最壞情況下為 $O(A(m, n))$。

## 申論及開發報告

### 選擇遞迴的原因

在本程式中，使用遞迴來計算阿克曼函數的主要原因如下：

1. **程式邏輯簡單直觀**  
   遞迴的寫法能夠清楚表達阿克曼函數「將問題拆解為更小維度」的多重遞迴特性。  
   例如，計算 $A(m,n)$ 當 $m>0$ 且 $n>0$ 的過程可分解為：  

   $$
   A(m,n) = A(m-1, A(m, n-1))
   $$

   當 $m$ 等於 0 時，直接返回 $n+1$，結束當前分支的遞迴。

2. **易於理解與實現**  
   遞迴的程式碼完美映射了數學上的分段定義公式，不需要複雜的迴圈或堆疊結構即可實作。  
   以本程式為例：  

   ```c
   int a(int m, int n){
       if(m==0) return n+1;
       else if (n==0) return a(m-1,1);
       else return a(m-1,a(m,n-1));
   }
   ```

3. **遞迴的語意清楚**  
   在程式中，阿克曼函數屬於非基本遞迴函數（non-primitive recursive function），其第三個條件使用了巢狀遞迴（呼叫自身作為自身的參數）。這種設計極難以單純的迭代迴圈來替換，遞迴寫法能最真實地還原其運算本質。

透過遞迴實作阿克曼函數，程式邏輯精簡且易於理解，特別適合展示多重遞迴的核心思想。然而，遞迴會因堆疊深度受到硬體限制，阿克曼函數的數值增長極快，當 $m$ 與 $n$ 值稍大（如 $m \ge 4$）時，即會引發 Stack Overflow 問題，實務上需了解其計算邊界。
