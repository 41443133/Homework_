# 41143133

作業一

## 解題說明

本題要求實現一個遞迴函式，計算並印出輸入字串的所有子集（即冪集 Powerset / 所有可能的字元組合）。

### 解題策略

1. 使用遞迴函式將問題拆解為「選擇包含」與「不包含」當前字元的兩個分支：
   - 分支一：將當前字元加入組合中，長度索引加 1 (`z(n+1, m, o+1)`)。
   - 分支二：不將當前字元加入組合中，長度索引不變 (`z(n+1, m, o)`)。
2. 當原始字串走到結尾（`n[0] == '\0'`）時，為結果陣列補上字串結束符號 `\0`，並輸出格式化結果 `[%s]`，此為遞迴的結束條件。
3. 主程式讀取使用者輸入的字串，準備一個空陣列儲存暫存結果，並呼叫遞迴函式。

## 程式實作

以下為主要程式碼：

```c
#include <stdio.h>

void z(char n[], char m[], int o){
    if(n[0] == '\0'){
        m[o] = '\0';
        printf("[%s]\n",m);
        return;
    }
    m[o] = n[0];
    z(n+1,m,o+1);
    
    z(n+1,m,o);
}


int main(){
    char a[10000];
    scanf("%s",&a);
    char b[10000];
    z(a,b,0);
}
```

## 效能分析

1. 時間複雜度：字串中的每一個字元都有「選」與「不選」兩種狀態。若字串長度為 $L$，則會產生 $2^L$ 種組合，時間複雜度為 $O(2^L)$。
2. 空間複雜度：空間複雜度主要取決於遞迴的堆疊深度與暫存陣列的長度，最壞情況下的最大遞迴深度為字串長度 $L$，空間複雜度為 $O(L)$。

1. 程式能正確列出輸入字串的所有可能組合（冪集），包含完全不選的空集合 `[]`。
2. 透過指標位移 `n+1` 與索引值 `o` 的搭配，成功在不更動原始字串的情況下完成遞迴分支。
3. 測試案例涵蓋了單一字元與多字元的輸入，輸出結果符合預期。

## 申論及開發報告

### 選擇遞迴的原因

在本程式中，使用遞迴來計算字串子集組合的主要原因如下：

1. **狀態樹的自然映射**  
   找出所有子集的問題本質上是一棵二元樹（Binary Tree）的深度優先搜尋（DFS）。每個節點代表對某個字元的抉擇（取或不取）。遞迴能非常直觀地將這種「分岔」的行為轉換為程式碼。

2. **程式邏輯極度簡化**  
   若要使用迭代（迴圈）來產生冪集，通常需要借助位元運算（Bitwise operations）或是額外維護複雜的堆疊結構。而遞迴只需兩次函數呼叫：  
   ```c
   z(n+1, m, o+1); // 取
   z(n+1, m, o);   // 不取
   ```
   即可完美表達邏輯，免去了繁瑣的狀態維護。

3. **語意清晰且易於擴展**  
   這段程式利用 `n+1` 縮小問題規模（往後推移一個字元），並利用 `o` 記錄當前組合的長度。當走到 `\0` 時，表示該路徑的抉擇已全數完成，直接輸出結果。此種設計不僅易讀，未來若要增加如「只印出特定長度的組合」等條件，也只需在終止條件中稍作修改即可。

透過遞迴實作冪集產生器，充分展示了遞迴在處理「組合與排列」問題上的強大優勢。不過需要注意的是，由於時間複雜度呈指數級別 $O(2^L)$增長，若輸入的字串過長（例如超過 30 個字元），運算時間將會大幅增加，實務應用中需留意輸入長度的限制。
